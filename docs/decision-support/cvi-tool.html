📐 روش‌شناسی CVI

I-CVI (Item-level CVI): درصد خبرگانی که یک شاخص را با امتیاز ۳ یا ۴ (مرتبط/بسیار مرتبط) ارزیابی کرده‌اند.

I-CVI = (تعداد خبرگان امتیاز ۳ یا ۴) / (کل خبرگان)

S-CVI/Ave (Scale-level CVI): میانگین I-CVI تمام شاخص‌ها.

S-CVI/Ave = Σ(I-CVI_i) / n

آستانه‌های قبول:

• I-CVI ≥ 0.78 (برای ۶ خبره یا بیشتر) — قبول ✅

• I-CVI = 0.70–0.78 — نیازمند بازبینی و اصلاح ⚠️

• I-CVI < 0.70 — رد و حذف یا بازطراحی ❌

• S-CVI/Ave ≥ 0.90 — روایی محتوای کل پرسشنامه قبول ✅
