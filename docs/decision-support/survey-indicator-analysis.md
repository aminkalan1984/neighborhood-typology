**وضعیت نهایی:** CONVERGED

# بخش اول — اصل بنیادین مأموریت

> هر شاخصی که بتوان مقدار آن را با اعتبار کافی از یک منبع داده غیرپیمایشی معتبر و قابل اتکا برای محله موردنظر استخراج یا استنتاج کرد، نباید به‌صورت پیش‌فرض پیمایشی محسوب شود.

> شاخص فقط زمانی «Survey-Required / پیمایش‌محور» محسوب شود که مقدار معتبر آن، یا اطلاعات لازم برای سنجش سازه زیربنایی آن، به‌صورت ذاتی به ادراک، نگرش، باور، هنجار، رفتار خودگزارش‌شده، تجربه زیسته، ترجیح، اعتماد، احساس، قصد، قضاوت یا سایر اطلاعاتی وابسته باشد که از منابع غیرپیمایشی به‌صورت معتبر، مستقیم و کافی قابل بازیابی نیست.

# بخش دوم — داده‌های ورودی و بازسازی سیستم

## معماری سیستم

سیستم «تصمیم‌یار جامع محله» یک موتور چهارگانه پیوسته است:

1. **موتور سنجش (Assessment):** ۴۰ شاخص در ۸ سرمایه → استانداردسازی ۰–۱۰۰ → امتیاز ۸ سرمایه (K_j) → امتیاز ۵ مرحله زنجیره C-A-U-E-O → سه‌گانه کیفیت Q, T, R
2. **موتور تشخیص (Diagnosis):** چهار شکاف اصلی (G_CA, G_AU, G_UE, G_EO) → مکان‌یابی گلوگاه ۵بعدی (سرمایه، گذار، مکان، گروه، زمان) → فرضیه‌های علّی رقیب → همگرایی شواهد
3. **موتور تجویز (Prescription):** نگاشت تشخیص به خانواده مداخله → سبد چندسرمایه‌ای → امتیاز اولویت (Severity × Population × Leverage × Feasibility × Equity) → فیلتر آسیب ناخواسته
4. **موتور یادگیری (Learning):** حسگری → تفسیر → بازخورد → انطباق → حافظه زنده → اصلاح قواعد

## زنجیره کیفیت C-A-U-E-O

هر شاخص روی یکی از پنج مرحله زنجیره برچسب‌خورده است:
- **C (ظرفیت):** چه چیزی وجود دارد؟
- **A (دسترسی):** آیا مردم می‌توانند به آن برسند؟
- **U (استفاده):** آیا واقعاً قابل استفاده است؟
- **E (تجربه):** مردم چه حسی دارند؟
- **O (پیامد):** چه تغییری در زندگی ایجاد می‌شود؟

## چهار جریان شواهد

سیستم چهار منبع مستقل شواهد را تمایز می‌دهد:
1. **عینی و ثبتی:** جمعیت، ساختمان، خدمت، اقتصاد، آلودگی
2. **مکانی (GIS):** شبکه، دسترسی، مخاطره
3. **رفتاری:** حضور، تردد، استفاده، مشارکت، ماندگاری
4. **ادراکی:** امنیت، تعلق، اعتماد، رضایت، هویت

## فرمول‌های کلیدی

**استانداردسازی شاخص مثبت:**
```
Z_i = 100 × (x_i - L_i)/(U_i - L_i)
```

**استانداردسازی شاخص منفی:**
```
Z_i = 100 × (U_i - x_i)/(U_i - L_i)
```

**امتیاز هر سرمایه:**
```
K_j = (Σ w_i Z_i) / (Σ w_i)
```

**چهار شکاف اصلی:**
```
G_CA = C - A,  G_AU = A - U,  G_UE = U - E,  G_EO = E - O
```

**عدالت:**
```
JusticeGap_i = P_best - P_worst
```

**اولویت مداخله:**
```
Priority = Severity × Population × Leverage × Feasibility
Priority* = Priority × Equity
```

# بخش سوم — بازسازی زنجیره تحلیلی

## برای هر خروجی سیستم:

### ۱. اندازه‌گیری (Measurement)
- **چه چیزی را اندازه‌گیری می‌کند:** سطح هر سرمایه محله روی مقیاس ۰–۱۰۰
- **سازه پشت آن:** هشت سرمایه + چهار شکاف + سه‌گانه Q/T/R
- **شاخص‌های لازم:** ۴۰ شاخص هسته (یکی از الزامی‌ترین شرایط)
- **داده تغذیه‌کننده:** Class A/B/C/D بسته به نوع شاخص
- **شاخص‌های مستقیم الگوریتم:** تمام ۴۰ شاخص مستقیماً وارد K_j می‌شوند

### ۲. تشخیص (Diagnosis)
- **چه چیزی را اندازه‌گیری می‌کند:** گلوگاه دقیق مسئله
- **سازه پشت آن:** شکاف زنجیره + عدالت + فرضیه علّی
- **شاخص‌های لازم:** ۴۰ شاخص هسته + پیمایش ۱۵ گویه‌ای (برای تشخیص علت)
- **اثر حذف هر شاخص پیمایشی:** بدون داده ادراکی، تشخیص علت فقط مبتنی بر داده عینی خواهد بود و فرضیه‌هایی مانند «ناامنی ادراکی» یا «عدم تعلق» قابل فرموله‌بندی نخواهند بود

### ۳. تجویز (Prescription)
- **چه چیزی را اندازه‌گیری می‌کند:** سبد مداخله بهینه
- **شاخص‌های لازم:** تشخیص معتبر (که خود وابسته به شاخص‌های پیمایشی است)
- **اثر حذف:** تجویز غیردقیق و نامتناسب با واقعیت ادراکی محله

# بخش پنجم — آزمون Survey Irreducibility

### برای هر شاخص CLASS D:

**S1 — اعتماد همسایگی:**
- داده پایگاه داده: ❌ — هیچ رکوردی از اعتماد ذخیره نمی‌شود
- داده ثبتی: ❌
- داده آماری: ❌
- داده GIS: ❌ — فاصله فیزیکی ≠ اعتماد
- داده سنسوری: ❌
- داده رفتاری دیجیتال: ⚠️ Weak Proxy — تعاملات شبکه اجتماعی نشان‌دهنده اعتماد نیست
- داده ترافیکی/مکانی: ❌
- **نتیجه: IRREDUCIBLY SURVEY-REQUIRED**

**S2 — تعلق محله‌ای:**
- تمام Proxyهای بررسی‌شده (ماندگاری سکونت، مالکیت مسکن، تراکم جمعیت): **Weak Proxy** — ممکن است فردی به دلیل فقر مانده باشد ولی تعلق نداشته باشد
- **نتیجه: IRREDUCIBLY SURVEY-REQUIRED**

**S3 — شبکه همکاری:**
- داده NGO/مسجد/رویداد: **Non-equivalent Proxy** — وجود نهاد ≠ وجود همکاری متقابل واقعی
- **نتیجه: IRREDUCIBLY SURVEY-REQUIRED**

**C3 — هویت محله‌ای:**
- نام تاریخی یا تراکم میراث: **Non-equivalent Proxy**
- **نتیجه: IRREDUCIBLY SURVEY-REQUIRED**

**C4 — مشارکت فرهنگی:**
- ثبت‌نام رسمی: **Weak Proxy** — فعالیت‌های غیررسمی و خودجوش را پوشش نمی‌دهد
- **نتیجه: IRREDUCIBLY SURVEY-REQUIRED**

### ۱۵ گویه ادراکی:

هر ۱۵ گویه یک سازه ادراکی/تجربی منحصربفرد را اندازه‌گیری می‌کند:
- **C1-S:** ادراک سبزینگی ≠ داده NDVI (سنجش‌ازدور) — ادراک شامل کیفیت، تمیزی و قابلیت استفاده است
- **C2-S:** ادراک کیفیت هوا ≠ PM2.5 خام — مردم ممکن است در منطقه‌ای با PM2.5 متوسط احساس آلودگی کنند و بالعکس
- **C3-S:** ادراک آلودگی صوتی ≠ سطح دسیبل — وابسته به نوع صدا و تحمل فردی
- **A1:** ادراک دسترسی حمل‌ونقل ≠ فاصله تا ایستگاه — شامل کیفیت، زمان انتظار و تناسب است
- **A2:** ادراک دسترسی خدمات ≠ تعداد خدمات روی نقشه — شامل تناسب، هزینه و کیفیت است
- **A3:** ادراک پیاده‌پذیری ≠ وضعیت فیزیکی پیاده‌رو — شامل امنیت و راحتی است
- **U1:** ادراک پیاده‌رو ≠ مشاهده میدانی — فقط خود فرد می‌تواند مانع واقعی را گزارش کند
- **U2:** ادراک روشنایی ≠ داده نور ماهواره‌ای — روشنایی ادراکی شامل امنیت و یکنواختی است
- **U3:** ادراک پارک ≠ تعداد پارک روی نقشه — شامل نگهداری، امنیت، امکانات و حضورپذیری است
- **E1:** احساس امنیت ≠ نرخ جرم ثبت‌شده — جرم ثبت‌شده فقط شکایات رسمی را پوشش می‌دهد
- **E2:** تعلق ≠ ماندگاری سکونت
- **E3:** اعتماد به همسایگان ≠ تعداد همسایگان آشنا
- **O1:** رضایت ≠ شاخص‌های عینی کیفیت — رضایت ترکیبی از انتظارات و واقعیت است
- **O2:** تنهایی ≠ هیچ داده عینی — صرفاً یک تجربه شخصی است
- **O3:** تمایل به ماندن ≠ مالکیت مسکن — شامل عوامل اجتماعی، اقتصادی و عاطفی است

# بخش هفتم — آزمون حداقل مجموعه کافی

### سؤال برای هر شاخص: اگر حذف شود، آیا سیستم همچنان Measurement + Diagnosis + Prescription معتبر تولید می‌کند؟

**S1 (اعتماد همسایگی):**
- حذف → تشخیص نمی‌تواند «بی‌اعتمادی» را به‌عنوان علت ضعف سرمایه اجتماعی مطرح کند
- حذف → تجویز نمی‌تواند مداخله «تسهیلگری اعتمادساز» تجویز کند
- **نتیجه: ضروری**

**S2 (تعلق محله‌ای):**
- حذف → تشخیص نمی‌تواند «فقدان تعلق» را شناسایی کند
- حذف → تجویز نمی‌تواند فعالیت‌های «هویت‌سازی محلی» تجویز کند
- **نتیجه: ضروری**

**S3 (شبکه همکاری):**
- حذف → تشخیص نمی‌تواند « فقدان شبکه همکاری» را شناسایی کند
- حذف → تجویز نمی‌تواند «شبکه‌سازی همسایگی» تجویز کند
- **نتیجه: ضروری**

**C3 (هویت محله‌ای):**
- حذف → تشخیص «عدم تمایز هویتی» را از دست می‌دهد
- **نتیجه: ضروری**

**C4 (مشارکت فرهنگی):**
- حذف → تجویز نمی‌تواند «فعال‌سازی فرهنگی» را هدفمند کند
- **نتیجه: Conditional — اگر C2 (فعال‌بودن دارایی) از منابع غیرپیمایشی موجود باشد، C4 ارزش افزوده ایجاد می‌کند ولی برای حداقل عملکرد ضروری نیست**

**۱۵ گویه ادراکی:**
- حذف تمام ۱۵ گویه → سیستم فقط مبتنی بر داده عینی است و نمی‌تواند فاصله «ادراک-واقعیت» را تشخیص دهد
- حذف یک گویه → آن لایه از زنجیره بدون پوشش ادراکی می‌ماند
- **نتیجه: هر ۱۵ گویه برای پوشش کامل پنج‌لایه زنجیره ضروری‌اند**

# بخش هشتم — آزمون حذف و جایگزینی

### برای هر شاخص نهایی:

**S1 — اعتماد همسایگی:**
- **Removal Test:** بدون آن، تشخیص علت در سرمایه اجتماعی فقط مبتنی بر رفتار (S3, S4) خواهد بود و «بی‌اعتمادی» به‌عنوان علت ناشناخته باقی می‌ماند
- **Substitution Test:** S3 (شبکه همکاری) نمی‌تواند جایگزین شود — اعتماد مقدم بر همکاری است
- **Proxy Test:** تعداد ملاقات‌ها، تعاملات آنلاین، تراکنش مالی: همگی Weak Proxy
- **Redundancy Test:** S2 (تعلق) سازه‌ای متفاوت است
- **نتیجه: IRREPLACEABLE**

**S2 — تعلق محله‌ای:**
- **Removal Test:** بدون آن، سیستم نمی‌تواند «دلبستگی مکانی» را بسنجد
- **Substitution Test:** S1 (اعتماد) سازه‌ای متفاوت است — فردی ممکن است به همسایگان اعتماد کند ولی تعلق به محله نداشته باشد
- **Proxy Test:** ماندگاری سکونت، مالکیت مسکن: Weak Proxy
- **نتیجه: IRREPLACEABLE**

**S3 — شبکه همکاری:**
- **Removal Test:** بدون آن، سیستم نمی‌تواند «ظرفیت اقدام جمعی» را ارزیابی کند
- **Substitution Test:** S4 (اقدام جمعی) فقط رفتار گذشته را نشان می‌دهد، نه ظرفیت بالقوه
- **Proxy Test:** تراکم NGO/مسجد: Non-equivalent Proxy
- **نتیجه: IRREPLACEABLE**

**C3 — هویت محله‌ای:**
- **Removal Test:** بدون آن، حوزه فرهنگی فقط با داده عینی (C1, C2) پوشش داده می‌شود
- **Proxy Test:** نام تاریخی، تراکم میراث: Non-equivalent Proxy
- **نتیجه: IRREPLACEABLE**

**C4 — مشارکت فرهنگی:**
- **Removal Test:** حذف آن باعث ایجاد شکاف در لایه «استفاده» حوزه فرهنگی می‌شود
- **Substitution Test:** C2 (فعال‌بودن دارایی) فقط وضعیت دارایی را نشان می‌دهد، نه مشارکت واقعی مردم
- **Proxy Test:** ثبت‌نام رسمی: Weak Proxy
- **نتیجه: Conditional — در صورت وجود C2 با داده معتبر، C4 تکمیلی است نه حیاتی**

## Measurement Sufficiency
حداقل داده پیمایشی لازم برای سنجش: ۵ شاخص هسته (S1, S2, S3, C3, C4) + ۱۵ گویه ادراکی = ۲۰ شاخص
- **آیا کافی است؟** بله — ۵ شاخص هسته K_S و K_C را پوشش می‌دهند و ۱۵ گویه پروفایل پنج‌لایه را کامل می‌کنند

## Diagnosis Sufficiency
حداقل داده لازم برای تشخیص: تمام ۴۰ شاخص هسته + ۱۵ گویه ادراکی
- **آیا کافی است؟** بله — بدون ۱۵ گویه ادراکی، شکاف «ادراک-واقعیت» قابل تشخیص نیست و علل اصطکاک فقط با داده عینی حدس زده می‌شود

## Prescription Sufficiency
حداقل داده لازم برای تجویز: تشخیص معتبر (که خود وابسته به ۲۰ شاخص پیمایشی است)
- **آیا کافی است؟** بله — سبد مداخله بر اساس شکاف‌های زنجیره و علل ادراکی قابل تولید است
