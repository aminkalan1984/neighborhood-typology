# بخش دوم — معماری داده و زنجیره ارزش

## زنجیره ارزش استخراج داده

```
منبع داده خام → پاکسازی → استانداردسازی → نرمال‌سازی → وزن‌دهی → امتیاز K_j
                                                                    ↓
                                                          Q, T, R (سه‌گانه)
                                                                    ↓
                                                          تشخیص + تجویز
```

## چهار جریان شواهد

| جریان | نوع داده | شاخص‌های مرتبط | ابزار استخراج |
|---|---|---|---|
| **عینی و ثبتی** | سرشماری، ثبت احوال، اصناف | H1, H3, H5, E1, E3 | API مرکز آمار، تأمین اجتماعی |
| **مکانی (GIS)** | نقشه، مسیر، POI | P1-P5, N1, N4, C1, R1-R3 | QGIS, PostGIS, Overpass API |
| **رفتاری** | سنسور، ترافیک، ماهواره | N2, N3, N5, G2, G4 | Google Earth Engine, STAC |
| **ادراکی** | پیمایش (۲۱ شاخص) | S1-S3, C3-C5, ۱۵ گویه | پرسشنامه دیجیتال |
