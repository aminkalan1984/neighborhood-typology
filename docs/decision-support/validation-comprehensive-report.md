## هدف

| لایه | معیار | ابزار | وضعیت |
|---|---|---|---|

# بخش سوم — روایی محتوا (CVI)

## ۳.۱ روش‌شناسی

**روش:** روش Content Validity Index بر اساس Lawshe (1975)

**پنل خبرگان (حداقل ۶ نفر):**
- ۲ متخصص شهرسازی و برنامه‌ریزی شهری
- ۲ متخصص جامعه‌شناسی و علوم اجتماعی
- ۱ متخصص روان‌شناسی سنجش و اندازه‌گیری
- ۱ متخصص مدیریت شهری و GIS

**مقیاس ارزیابی ۴ نقطه‌ای:**
| امتیاز | معنا |
|---|---|
| ۱ | اصلاً مرتبط |
| ۲ | تا حدی مرتبط |
| ۳ | مرتبط |
| ۴ | بسیار مرتبط |

**سه معیار ارزیابی:**
- **مرتبط بودن (Relevance):** آیا شاخص سازه موردنظر را می‌سنجد؟
- **واضح بودن (Clarity):** آیا سؤال قابل فهم و بدون ابهام است؟
- **ضرورت (Necessity):** آیا بدون این شاخص، تشخیص/تجویز ناقص می‌شود؟

# بخش چهارم — پایایی test-retest (ICC)

## ۴.۱ روش‌شناسی

**روش:** Intraclass Correlation Coefficient — مدل دوطرفه با اثرات تصادفی ICC(2,1)

**شرایط اجرا:**
- فاصله بین دو نوبت: ۱۴ روز
- حجم نمونه: حداقل ۳۰ پاسخ‌دهنده
- سطح اطمینان: ۹۵٪

**فرمول:**
```
ICC(2,1) = (MSR - MSE) / (MSR + (k-1)×MSE + k×(MStarget - MSE)/n)
```

# بخش پنجم — پایایی درونی (Cronbach's Alpha)

## ۵.۱ روش‌شناسی

**فرمول Spearman-Brown:**
```
α = (k / (k-1)) × (1 - Σσ²_i / σ²_total)
```

## ۵.۲ نتایج Alpha پیش‌بینی

## پیوست الف: فرمول‌های کلیدی

```
I-CVI = (تعداد خبرگان امتیاز ≥ ۳) / (کل خبرگان)

ICC(2,1) = (MSR - MSE) / (MSR + (k-1)MSE + k(MStarget - MSE)/n)

α = (k/(k-1)) × (1 - Σσ²_i / σ²_total)

Z_i = 100 × (x_i - L_i) / (U_i - L_i)    [شاخص صعودی]
Z_i = 100 × (U_i - x_i) / (U_i - L_i)    [شاخص نزولی]

K_j = Σ(w_i × Z_i) / Σ(w_i)

G_CA = C - A    G_AU = A - U    G_UE = U - E    G_EO = E - O
```
