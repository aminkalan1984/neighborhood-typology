# بخش دوم — روش نمونه‌گیری

## ۲.۱ طرح نمونه‌گیری چندمرحله‌ای خوشه‌ای

### مرحله ۱: انتخاب پهنه‌ها (Cluster Selection)

**روش:** نمونه‌گیری تصادفی متناسب (Probability Proportional to Size — PPS)

1. ** تعیین جامعه هدف:** تمام پهنه‌های ۴۰۰ خانواری شهر موردنظر
2. **طبقه‌بندی پهنه‌ها بر اساس پروفایل:**
   - پیشرفته (Advanced)
   - میانی (Mid)
   - محروم (Deprived)
   - سرمایه پنهان (Hidden Capital)
3. **وزن‌دهی بر اساس جمعیت:** احتمال انتخاب هر پهنه متناسب با جمعیت آن
4. **تعداد پهنه‌های انتخابی:** حداقل ۲ پهنه از هر طبقه (برای مقایسه بین‌تیپی)

### مرحله ۲: انتخاب خانوارها (Within-Cluster Selection)

**روش:** نمونه‌گیری تصادفی ساده (SRS) از فهرست خانوارها

1. **فهرست مبنا:** لیست خانوارهای هر پهنه از آخرین سرشماری یا ثبت احوال
2. **شماره‌گذاری:** هر خانوار یک شماره منحصربفرد
3. **انتخاب تصادفی:** با استفاده از مولد اعداد تصادفی
4. **جایگزینی:** برای هر پاسخ‌دهنده عدم دسترسی/امتناع، ۲ جایگزین مشخص شود

### مرحله ۳: انتخاب پاسخ‌دهنده

**روش:** قاعده کیس

| اولویت | معیار | توضیح |
|---|---|---|
| ۱ | سرپرست خانوار | تصمیم‌گیر اصلی |
| ۲ | بزرگ‌ترین فرد بالغ حاضر | در صورت عدم دسترسی سرپرست |
| ۳ | هر فرد بالغ ساکن حداقل ۲ سال | در صورت عدم دسترسی اول و دوم |

**محدودیت سنی:** حداقل ۱۸ سال  
**محدودیت سکونت:** حداقل ۲ سال سکونت متوالی در پهنه

# بخش سوم — حجم نمونه

## ۳.۱ فرمول محاسبه حجم نمونه

### فرمول پایه (برای هر پهنه)

$$n = \frac{Z^2 \cdot p \cdot (1-p)}{E^2} \cdot DEFF \cdot \frac{1}{1-r}$$

که در آن:
- **n** = حجم نمونه موردنیاز
- **Z** = مقدار Z برای سطح اطمینان ۹۵٪ = ۱.۹۶
- **p** = تنوع تخمینی شاخص (برای حداکثر تنوع = ۰.۵)
- **E** = حاشیه خطای مجاز = ۰.۰۵ (خطای ۵٪)
- **DEFF** = ضریب اثر طراحی (برای نمونه‌گیری خوشه‌ای = ۱.۵ تا ۲.۰)
- **r** = نرخ عدم پاسخ پیش‌بینی‌شده = ۰.۱۵ (۱۵٪)

### محاسبه عددی

```
n = (1.96² × 0.5 × 0.5) / 0.05² × 1.5 × 1/(1-0.15)
n = (3.8416 × 0.25) / 0.0025 × 1.5 × 1.176
n = 0.38416 / 0.0025 × 1.5 × 1.176
n = 153.66 × 1.5 × 1.176
n ≈ 270 خانوار به‌ازای هر پهنه
```

### حجم واقعی (با گرد‌کردن)

| پارامتر | مقدار |
|---|---|
| حجم خام | ۲۷۰ |
| حجم پس از گردکردن | ۲۷۵ |
| جایگزین‌ها (۱۵٪) | ۴۱ |
| **حجم کل نمونه به‌ازای هر پهنه** | **۲۷۵ + ۴۱ = ۳۱۶ خانوار** |

## ۳.۲ حجم نمونه به تفکیک حالت تحلیل

| حالت تحلیل | حداقل پهنه | حداقل خانوار به‌ازای هر پهنه | حداقل کل خانوار |
|---|---|---|---|
| **cities متوسط (تا ۵۰۰ هزار نفر)** | ۶ پهنه | ۱۰۰ | ۶۰۰ |
| **cities بزرگ (۵۰۰K–۲M نفر)** | ۱۲ پهنه | ۱۵۰ | ۱,۸۰۰ |
| **کلانشهرها (>۲M نفر)** | ۲۴ پهنه | ۲۰۰ | ۴,۸۰۰ |

## ۳.۳ حداقل نمونه برای تفکیک زیرگروهی

برای تحلیل عدالت (Justice Gap) بین گروه‌های جمعیتی، حداقل نمونه هر گروه:

| گروه | حداقل نمونه | دلیل |
|---|---|---|
| جنسیت (مرد/زن) | ۵۰ نفر هر کدام | مقایسه دوگروهی با قدرت ۸۰٪ |
| سن (۴ گروه) | ۳۰ نفر هر کدام | ANOVA چهارگروهی |
| وضعیت اشتغال (شاغل/بیکار/بازنشسته) | ۳۰ نفر هر کدام | مقایسه سه‌گروهی |
| مالک/اجاره | ۴۰ نفر هر کدام | مقایسه دوگروهی با قدرت ۸۰٪ |

## ۳.۴ فرمول تعیین حجم نمونه پهنه‌ای (Level-Specific)

برای اطمینان از کفایت آماری در سطح پهنه:

$$n_{p} = \frac{Z^2_{\alpha/2} \cdot \sigma^2_p}{E^2_p}$$

که:
- **σ_p** = انحراف معیار شاخص در سطح پهنه (از پایلوت)
- **E_p** = حاشیه خطای مجاز در سطح پهنه = ۰.۰۸ (خطای ۸٪ — بالاتر از سطح شهر)

**نتیجه عملی:** حداقل ۱۰۰ خانوار به‌ازای هر پهنه برای تفکیک در سطح پهنه الزامی است.

| H2 | آیا مهارت‌هایی دارید که بتوانید آن‌ها را در بازار کار عرضه کنید؟ (بله/خیر + توضیح) | H1 < ۵۰ |
| H4 | آیا شغل فعلی شما با مهارت‌هایتان تناسب دارد؟ (لیکرت ۱–۵) | H3 < ۶۰ |
| S4 | آیا در ۶ ماه گذشته با همسایگان خود در تصمیم‌گیری محلی مشارکت کرده‌اید؟ (بله/خیر + توضیح) | S3 < ۴۰ |
| S5 | آیا تاکنون با همکاری همسایگان مشکلی را در محله حل کرده‌اید؟ (بله/خیر + توضیح) | S4 < ۴۰ |
| G1 | آیا در جلسات شورای محلی یا مجمع عمومی مسجد شرکت می‌کنید؟ (لیکرت ۱–۵) | G2 < ۵۰ |
| G3 | آیا نهادهای محله (شورا، مسجد، شهرداری) با یکدیگر هماهنگ عمل می‌کنند؟ (لیکرت ۱–۵) | G2 < ۵۰ |
| R5 | چقدر از اینترنت برای کار و زندگی روزمره استفاده می‌کنید؟ (لیکرت ۱–۵) | R3 < ۵۰ |

## ۴.۲ منطق پرش (Skip Logic)

```
شروع
  ↓
صفحه ۱: اطلاعات جمعیت‌شناختی (همه)
  ↓
صفحه ۲: شاخص‌های هسته (همه)
  ↓
صفحه ۳: گویه‌های ادراکی (همه)
  ↓
بررسی مقادیر صفحه ۲
  ├── H1 < ۵۰؟ ──بله──→ صفحه ۴: H2
  ├── H3 < ۶۰؟ ──بله──→ صفحه ۴: H4
  ├── S3 < ۴۰؟ ──بله──→ صفحه ۴: S4
  │     └── S4 < ۴۰؟ ──بله──→ صفحه ۴: S5
  ├── G2 < ۵۰؟ ──بله──→ صفحه ۴: G1, G3
  └── R3 < ۵۰؟ ──بله──→ صفحه ۴: R5
```

# بخش نهم — پروتکل‌های میدانی

## ۹.۱ پروتکل مراجعه

### مراجعه اول

```
۱. معرفی: "سلام، من [نام] از تیم پیمایش [نام سازمان] هستم."
۲. ارائه کارت شناسایی
۳. توضیح هدف: "ما در حال بررسی کیفیت زندگی در محله شما هستیم."
۴. تأکید بر اعتماد: "پاسخ‌های شما محرمانه است و فقط به صورت تجمیعی استفاده می‌شود."
۵. کسب رضایت: "آیا مایل به شرکت هستید؟"
۶. اگر بله: ادامه مصاحبه
۷. اگر خیر: "متشکرم. آیا مایلید در آینده با شما تماس بگیریم؟"
۸. ثبت وضعیت در اپلیکیشن
```

### مراجعه دوم (در صورت عدم دسترسی)

```
۱. تلاش اول: ساعت متفاوت (صبح/عصر)
۲. تلاش دوم: روز متفاوت (حداقل ۲ روز بعد)
۳. تلاش سوم: مراجعه به همسایه برای کسب اطلاعات تماس
۴. پس از ۳ تلاش ناموفق: ثبت "عدم دسترسی" و جایگزینی
```

## ۹.۲ پروتکل اخلاقی

| اصل | اجرا |
|---|---|
| **رضایت آگاهانه** | توضیح شفاهی + امضا/تأیید شفاهی (برای بی‌سوادان) |
| **محرمانگی** | عدم ثبت نام/کد ملی در فرم اصلی |
| **ناشناسی** | هر پاسخ‌دهنده فقط یک شماره رندوم دارد |
| **حق انصراف** | در هر مرحله امکان انصراف بدون توضیح |
| **آسیب‌پذیری** | اگر پاسخ‌دهنده ناراحت شد، مصاحبه متوقف شود |
| **بازخورد** | ارائه شماره تماس برای سؤالات بعدی |

## ۹.۳ پروتکل شرایط خاص

| شرط | عمل |
|---|---|
| پاسخ‌دهنده درخواست پول کند | مؤدبانه رد کردن + توضیح داوطلبانه بودن |

| حذف Straightlining (> ۴ پاسخ یکسان متوالی) | علامت‌گذاری + بررسی |
| تبدیل نامعتبر به NA | ثبت دلیل |

## ۱۰.۳ بازنرمال‌سازی مقادیر گمشده

### قاعده Safe-Drop

```
اگر وزن شاخص‌های گمشده < ۴۰٪ کل وزن لایه باشد:
    وزن باقیمانده بازنرمال‌سازی شود
    لایه با برچسب "low_confidence" علامت‌گذاری شود

اگر وزن شاخص‌های گمشده ≥ ۴۰٪ کل وزن لایه باشد:
    لایه از محاسبه حذف شود
    خروجی: NaN با برچسب "insufficient_data"
```

### فرمول بازنرمال‌سازی وزن

$$w'_i = \frac{w_i}{\sum_{j \in available} w_j}$$

## ۱۰.۴ استانداردسازی شاخص‌ها

### شاخص‌های صعودی (Positive)

$$Z_i = 100 \times \frac{x_i - L_i}{U_i - L_i}$$

### شاخص‌های نزولی (Negative — مانند C3-S, O2)

$$Z_i = 100 \times \frac{U_i - x_i}{U_i - L_i}$$

### پارامترهای استانداردسازی

| شاخص | L_i (حداقل نظری) | U_i (حداکثر نظری) | جهت |
|---|---|---|---|
| S1–S3, C3–C5 | ۱ | ۵ | صعودی |
| C1-S, C2-S, A1–A3, U1–U3 | ۱ | ۵ | صعودی |
| C3-S | ۱ | ۵ | **نزولی** |
| E1-S, E2-S, E3-S | ۱ | ۵ | صعودی |
| O1, O3 | ۱ | ۵ | صعودی |
| O2 | ۱ | ۵ | **نزولی** |

## ۱۰.۵ محاسبه امتیاز سرمایه

$$K_j = \frac{\sum_{i \in j} w_i \cdot Z_i}{\sum_{i \in j} w_i}$$

### وزن‌دهی اولیه (پیش‌فرض)

| شاخص | وزن | دلیل |
|---|---|---|
| S1 (اعتماد) | ۱.۲ | اهمیت بالا در K_S |
| S2 (تعلق) | ۱.۰ | وزن استاندارد |
| S3 (شبکه) | ۱.۰ | وزن استاندارد |
| C3 (هویت) | ۱.۰ | وزن استاندارد |
| C4 (مشارکت) | ۰.۸ | وزن پایین‌تر (conditionally essential) |
| C5 (انتقال) | ۰.۸ | وزن پایین‌تر (conditionally essential) |
| ۱۵ گویه ادراکی | ۱.۰ هر کدام | وزن یکسان |

## ۱۰.۶ محاسبه Gap Detection (فاصله ادراک-واقعیت)

برای هر گویه ادراکی:

$$Gap_i = Z_{objective,i} - Z_{perceptual,i}$$

- **Gap > ۰:** مردم وضعیت را بهتر از واقعیت ادراک می‌کنند (خوش‌بینی)
- **Gap < ۰:** مردم وضعیت را بدتر از واقعیت ادراک می‌کنند (بدبینی)
- **|Gap| > ۲۰:** شکاف معنادار → نیازمند مداخله

| شاخص عینی | شاخص ادراکی | Gap |
|---|---|---|
| N2 (پوشش سبز — سنجش‌ازدور) | C1-S (ادراک فضای سبز) | N2标准化 − C1-S标准化 |
| N3 (کیفیت هوا — PM2.5) | C2-S (ادراک کیفیت هوا) | N3标准化 − C2-S标准化 |
| P5 (دسترسی حمل‌ونقل — GIS) | A1 (ادراک حمل‌ونقل) | P5标准化 − A1标准化 |
| P4 (دسترسی خدمات — GIS) | A2 (ادراک خدمات) | P4标准化 − A2标准化 |
| P2 (پیوستگی معابر — GIS) | A3 (ادراک پیاده‌پذیری) | P2标准化 − A3标准化 |
